# Landing BlokirJudi

Landing berbasis Astro tanpa framework client dan tanpa analytics—ngebut sekaligus gampang dikontribusikan.

```bash
npm install
npm run dev
npm run build
```

Sebelum rilis, ganti tautan GitHub/store dan aktifkan tombol donasi setelah detail QRIS, GoPay, serta Bank Jago siap.
